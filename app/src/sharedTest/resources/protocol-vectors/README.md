# Protocol test vectors

Copies of `website/protocol/vectors/*.json`, generated by the reference implementation
(`website/protocol/scripts/generate-vectors.ts`). The server's TypeScript and Killit's Kotlin are
both checked against these same files, which is what keeps the two implementations of
`website/protocol/SPEC.md` in agreement.

Never edit them here. When the protocol changes, regenerate them in the website repository and
copy all of them over together; `org.tamodak.killit.protocol.*VectorsTest` then shows what Killit
has to change.
